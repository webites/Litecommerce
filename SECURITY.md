# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting for this repository
(Security tab, "Report a vulnerability"). Include the affected version or
commit, the steps to reproduce and the impact you expect.

## Supported versions

Litecommerce has not had a stable release yet. Until it does, only the latest
state of the default branch receives fixes. This section will list supported
release lines once releases exist.

## Scope

In scope: the Litecommerce core in this repository. Third-party plugins and
themes are separate code run with the permissions of the application; report
problems in them to their authors.
